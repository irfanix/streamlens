# Demo photos

Put 10 to 20 real stream photos here (JPG, PNG or WEBP). They become the demo
assessments on the map the next time the app starts with an empty database.

Name each file with a prefix so the demo measurements match the picture:

| Prefix | Use for | Example |
|---|---|---|
| `clear_` | clean, clear stream | `clear_1.jpg` |
| `algae_` | green water, algae | `algae_1.jpg` |
| `muddy_` | brown, murky water | `muddy_1.jpg` |
| `trash_` | plastic or trash in water | `trash_1.jpg` |
| `stagnant_` | still water, puddles | `stagnant_1.jpg` |
| `blurry_` | a deliberately blurry or dark photo (shows the validation warning) | `blurry_1.jpg` |

Keep each file under 5 MB (choose "Medium" or "Large" when downloading).
